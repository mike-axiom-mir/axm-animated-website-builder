# Licensing boundary

AXM Animated Website Builder separates the builder from the websites people build in it.

## The model

| Layer | Default permission |
|---|---|
| A tile or asset created in AXM Animated Website Builder | Portable Creator Output; the creator chooses its licence. |
| A combined game, website, world, or application | Portable Creator Output; it may be exported, edited elsewhere, shared, or sold. |
| AXM Animated Website Builder engine and workshop | PolyForm Noncommercial 1.0.0: noncommercial use, modification, and redistribution are allowed. |
| Commercial use of AXM Animated Website Builder to make Creator Output | Allowed by `CREATOR_OUTPUT_PERMISSION.md`. |
| Selling, hosting, monetizing, bundling, or commercially redistributing AXM Animated Website Builder itself | Requires separate written permission after a grounded use case is presented. |

## What “no lock” means

A creation is matter, not a hostage of the workshop. Exported Creator Output
must be able to leave AXM Animated Website Builder without AXM Animated Website Builder claiming ownership or forcing
the engine's noncommercial terms onto the creation.

An export should therefore use open, inspectable formats and avoid embedding
the AXM Animated Website Builder engine. If an export later needs a AXM Animated Website Builder runtime component,
that component needs its own explicit redistributable licence. No runtime right
is silently implied.

This boundary does not erase copyrights, trademarks, patents, licences, or
other rights in third-party material included by a creator.

## The shortest version

> Earning with AXM Animated Website Builder is permitted. Earning from AXM Animated Website Builder requires a
> grounded case and separate written permission.

The legally operative files are `LICENSE` and
`CREATOR_OUTPUT_PERMISSION.md`. This page is a plain-language explanation.
